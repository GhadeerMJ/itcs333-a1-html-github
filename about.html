Why I Chose Computer Science

I like solving problems and seeing my code work. Technology also opens many career options.

How My Goals Connect

My goals support each other. Better problem-solving skills make it easier to learn a new programming language, and both help me finish my degree with strong results. Each goal is a step toward working in the IT field.

How I Will Improve My Problem-Solving Skills

This is my first priority, so I have a clear plan for it:

  1. Read the problem carefully and understand what is asked
  2. Break it into smaller steps
  3. Write a simple solution first, then improve it
  4. Practice with one coding puzzle every day
  5. Review my mistakes and learn from them

My Favorite Advice

Practice a little every day, and progress will come.
